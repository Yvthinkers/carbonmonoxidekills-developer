# Carbon Monoxide Kills: rebrand site (v3)

Static 21-page site generated by Python (no dependencies beyond the standard library).

```
v3/content/*.html   page bodies, each with a JSON meta block on top
v3/assets/          CSS, JS (site.js, home.js), logos, images
v3/build.py         generator -> v3/dist (dev preview), v3/art (claude.ai artifact), v3/live (production)
apply_client_changes_2026-10-29.py   one-shot script that applied Rob's 11-point change list (already applied; do not re-run)
deploy/             upload scripts and the dev .htaccess
ec2/site/           robots.txt and .htaccess for the noindex dev preview
logo/               logo source
```

Build: `python3 v3/build.py`

- `dist/`  noindex dev preview (EC2 / dev.carbonmonoxidekills.com)
- `live/`  production: indexable, canonical tags, phone-only CTAs instead of forms, `sitemap-new.xml`
  Ships no `.htaccess` / `robots.txt`: the WordPress/Yoast site on the same cPanel account owns them.
  It is an overlay on `public_html`: roll back by deleting the added files.

Deploy: `deploy/upload_ftp.sh` (production, FTP creds via env vars) and `deploy/deploy_ec2_dev.sh` (dev preview).
Never commit credentials.
