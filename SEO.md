# SEO implementation: carbonmonoxidekills.com

Reviewed against the "SEO Points" document (50 items + A–E). That document is written for a Next.js app with a
database. This site is a static site generated by Python (`v3/build.py`) and served from cPanel next to the
existing WordPress site, so each item is mapped to its equivalent here. Items that only exist in Next.js or need
a database/admin panel are marked **N/A** with the reason.

**Where the SEO code is**

| File | What it does |
|---|---|
| `v3/seo.py` | Central SEO config and generators: meta/canonical/robots, Open Graph, Twitter Card, JSON-LD, sitemap, robots.txt, verification and GA4 hooks |
| `v3/build.py` | Calls `seo.py` for every page; `live` = production build (indexable), `dist` = dev preview (noindex) |
| `v3/seo_audit.py` | Automated checks on the build; fails on any error |
| `v3/state_pages.json` | The 51 state lawyer pages (50 states + DC) the state lists link to; every URL checked to return 200 |
| `v3/tools/make_images.py` | Generates the 1200×630 share image and PNG icons |
| `deploy/htaccess-seo.conf` | HTTPS + www + `/index.html` redirects for the cPanel `.htaccess` (tested on Apache) |
| `v3/live/` | The built production site, committed so the output can be reviewed |

**Verify:** `cd v3 && python3 build.py && python3 seo_audit.py` → `21 pages, 0 errors, 0 warnings`.
All JSON-LD (260 typed nodes) was also checked against the schema.org vocabulary: no unknown types or properties.
